# Changelog

All notable changes to `ricventu/laravel-anti-xss` will be documented in this file.

## v1.0.0 - 2026-05-06

Initial release: Facade, service singleton, `clean_xss` validation rule, `CleanXss` rule object, `CleanXssInput` middleware, `@xss` Blade directive and `anti_xss()` helper around [voku/anti-xss](https://github.com/voku/anti-xss).

## 1.0.0 - 2026-05-06

- Initial release: Facade, service singleton, `clean_xss` validation rule and
  `CleanXss` rule object, opt-in `CleanXssInput` middleware, `@xss` Blade
  directive and `anti_xss()` helper around [voku/anti-xss](https://github.com/voku/anti-xss).
